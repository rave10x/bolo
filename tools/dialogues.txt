## int-tech|Explaining a technical concept|Technical cheez samjhana|🧠|Interview|Interviewer
Q: Can you explain the difference between an ArrayList and a LinkedList?
Y: Both store a list of items. An ArrayList uses an array internally, so reading an item by index is very fast. A LinkedList connects items with pointers, so adding or removing in the middle is easier, but reading by index is slow.
Q: Which one would you use most of the time?
Y: Usually an ArrayList, because most programs read data more often than they insert in the middle, and it uses memory more efficiently.
Q: What is the time complexity of searching in a HashMap?
Y: On average it is constant time, order of one, because the key is converted to a hash that points to the right bucket. In the worst case, with many collisions, it can become order of n.
Q: Nicely explained. What happens when two keys have the same hash?
Y: That is called a collision. Java stores both entries in the same bucket, in a list or a tree, and compares the keys to find the right one.
