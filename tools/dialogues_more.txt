## int-tech|6
Q: What is the difference between an abstract class and an interface?
Y: An interface describes what a class can do, and a class can implement many interfaces. An abstract class can also hold shared fields and some ready code, but a class can extend only one of them.
Q: When would you choose one over the other?
Y: If I only need a contract, I use an interface. If several classes share common code and state, I use an abstract class. These days I usually start with an interface because it is more flexible.
Q: What is a primary key in a database, and why is it important?
Y: A primary key uniquely identifies each row in a table. It cannot be empty or repeated, so other tables can refer to it safely, and the database can find a row quickly.
Q: How would you make a slow query faster?
Y: First I would look at the query plan to see where time is spent. Often adding an index on the column in the where condition helps. I would also select only the columns I need.

Q: Let us try another one. Can you explain what a deadlock is?
Y: A deadlock happens when two threads each hold a resource and wait for the other to release theirs, so neither can continue. I have only seen it in examples, not in production.
Q: How could you prevent it?
Y: One way is to always acquire locks in the same order. Another way is to use a timeout so that a thread does not wait forever. I am not sure which one is better in every case.
Q: What would you do if you got stuck on a problem like this at work?
